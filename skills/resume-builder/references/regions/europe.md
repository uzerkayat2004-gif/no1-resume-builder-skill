# Continental Europe profile

Practices differ by country, sector, and employer.

- A4 is the default paper size.
- Match the document language to the posting.
- Europass is an option when requested or useful; it is not mandatory for every European role.
- Europass supports many languages and can include a photo, but photo expectations vary. Do not add one by default without target-country/application context.
- Avoid sensitive personal data unless explicitly required and appropriate.
- Follow country-specific and employer instructions over generic “European CV” advice.

Source: https://europass.europa.eu/en/create-europass-cv
