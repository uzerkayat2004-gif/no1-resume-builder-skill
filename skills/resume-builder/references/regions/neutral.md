# Neutral private-sector profile

Use when target geography is unknown.

- No photo or protected personal details by default.
- City/region is enough; omit street address.
- One-column reverse chronology.
- Standard headings in the document language.
- Letter or A4 based on known locale; otherwise ask only if rendering now.
- One to two pages depending on relevant evidence.
- Application instructions control file type and requested fields.

Do not describe this profile as globally correct. It is a privacy-preserving fallback.
