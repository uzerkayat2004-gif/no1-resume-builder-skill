# Security and privacy

The bundled helper makes no network calls. An AI host may still process attachments under its own data controls. Treat career records and generated resumes as sensitive personal data.

- Do not commit real candidate records.
- Keep temporary render directories private and delete them when no longer needed.
- Review generated document metadata before sharing.
- Do not call external services unless the user explicitly requests it and understands what data will be sent.
- Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/uzerkayat2004-gif/no1-resume-builder-skill/security/advisories/new). Do not open a public issue for an undisclosed vulnerability.

The renderer does not submit applications, send email, upload files, or contact employers.
